# Traders Care — лендинг

Главная страница traderscare.io: Next.js 15 (App Router), React 19, Tailwind CSS 3, motion.

Инструкция по переносу на сайт-платформу Traders Care (в том числе для Claude Code) — в [CLAUDE.md](CLAUDE.md).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3010
npm run build && npm start
npm run lint       # ESLint (конфиг next/core-web-vitals + next/typescript)
npm run typecheck  # TypeScript без сборки
```

## Языки и адреса

- `/` — английский, `/ru` — русский, `/uk` — украинский (`src/middleware.ts`).
- Все тексты — в `src/i18n/dictionaries/{ru,en,uk}.ts`. Форма словаря задаётся русским файлом, остальные должны ей соответствовать (это проверяет TypeScript).
- Язык переключается без перезагрузки страницы.

## Темы

Тема задаётся атрибутом `data-theme="dark" | "light"` на `<html>`, выбор хранится в `localStorage` под ключом `theme` (как на платформе). Цвета — CSS-переменные в `src/styles/tokens.css`, в Tailwind они доступны как `lp-*` (`text-lp-text`, `bg-lp-ground` и т. д.).

## Структура

```
src/app/[locale]/        страница и метаданные
src/components/sections/ блоки лендинга (порядок — в src/app/[locale]/page.tsx)
src/components/site/     шапка, подвал, переключатели языка и темы
src/components/ui/       кнопка, контейнер, анимации появления
src/lib/                 форматирование, гомография для экранов на фото, переходы
public/media/            изображения блоков и кадры первого экрана
```

## Первый экран

Ноутбук открывается при прокрутке: это 144 кадра видео, которые рисуются на `<canvas>` (`hero-laptop.tsx`). Наборы кадров:

- `public/media/hero/lid/` — тёмная тема, 1920 px;
- `public/media/hero/lid-m/` — тёмная тема, телефон, 960 px;
- `public/media/hero/lid-light/`, `lid-light-m/` — светлая тема.

Интерфейс на экранах устройств (ноутбук, телефон, планшет, планшет на столе) свёрстан кодом и натянут на фото через матрицу перспективы. Координаты экранов в кадрах записаны в константах в начале каждого компонента. Если картинку или видео заменить, координаты нужно перемерить.

## Что заполнить

В коде пометкой `[ДАННЫЕ]` отмечены места с временными данными: ссылки на калькуляторы, документы, соцсети и поддержку, число трейдеров в полосе доверия. Демонстрационные цифры в интерфейсах подписаны на странице как «Пример данных».

Картинка для превью ссылки в соцсетях (`og:image`) не задана — метаданные страницы в `src/app/[locale]/layout.tsx`.

## Доступность и движение

Все анимации учитывают системную настройку `prefers-reduced-motion`: при ней страница сразу показывает конечное состояние.
